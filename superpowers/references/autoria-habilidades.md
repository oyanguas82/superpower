# Autoría de habilidades

Adaptación del propósito de `writing-skills`. Úsala para solicitudes de creación o mejora de habilidades, no para convertir automáticamente cada tarea resuelta en una habilidad.

Si hay una habilidad de creación disponible en el entorno, úsala como procedimiento específico de autoría. Esta referencia aporta el enfoque de evaluación de Superpowers; no sustituye los requisitos del formato de destino.

Identifica qué decisiones no obvias debe mejorar la habilidad, con qué solicitudes debería activarse y cuáles quedarían fuera. Mantén un punto de entrada breve; distribuye instrucciones extensas por modo y enlaza cada referencia donde se necesite. Crea scripts solo si una operación repetida o frágil se beneficia de ejecución determinista.

## Evaluación proporcional

Para una modificación pequeña, comprueba estructura, referencias, descubrimiento y coherencia con la solicitud. Para una habilidad compleja o con fallos de comportamiento conocidos, utiliza un caso realista con entradas y un resultado observable.

Si una evaluación con agentes está disponible y autorizada, proporciona la solicitud y los recursos mínimos en un espacio aislado, sin revelar la respuesta que esperas. Cuando aporte valor, compara el comportamiento sin la habilidad y con ella. Evalúa acciones y artefactos, no que aparezcan las mismas frases o encabezados.

La evaluación no debe publicar, enviar mensajes ni afectar sistemas reales sin autorización. Si no se ejecuta una prueba de comportamiento independiente, informa únicamente de las comprobaciones que sí se realizaron.

Mejora instrucciones a partir de resultados observados: corrige una activación demasiado amplia, una referencia inaccesible o una decisión equivocada concreta. Evita acumular reglas universales para cada ejemplo. Conserva licencias y atribuciones cuando adaptes material ajeno.
